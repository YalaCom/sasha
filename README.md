# 💅 Ноготочки за правильные ответы

Небольшая игра-сюрприз для жены. Победа — только когда **все ответы правильные**. У мужа есть защищённая паролем админ-панель с результатами и выбранными ответами.

## Структура
- `public/index.html` — страница игры
- `public/admin.html` — вход администратора
- `public/styles.css`, `public/app.js`, `public/admin.js` — интерфейс
- `functions/api/questions.js` — вопросы без правильных ответов
- `functions/api/submit.js` — проверка на сервере и запись попытки в KV
- `functions/api/admin.js` — список попыток с проверкой пароля
- `functions/_lib/quiz.js` — пример вопросов и правильных ответов (перед настоящей игрой заменить!)

## Как подключить Cloudflare Pages (через браузер)
1. Открой Cloudflare → **Workers & Pages** → **Create application** → **Pages** → **Connect to Git**.
2. Выбери GitHub-репозиторий **YalaCom/sasha** и ветку **main**.
3. Framework preset: **None**. Build command: **пусто**, Output directory: **public**, Root directory: репозиторий (/).
4. Создай KV namespace (например, `sasha-quiz-results`).
5. Открой проект Pages → **Settings → Bindings → Add → KV namespace**. Variable name: **QUIZ_RESULTS**. Привяжи namespace.
6. Проект Pages → **Settings → Variables and Secrets → Add**. Создай **ADMIN_PASSWORD** с длинным уникальным паролем; выбери тип Secret, если он доступен.
7. Переразверни проект (Redeploy), чтобы новые bindings вступили в силу.

После этого:
- `https://<твой-проект>.pages.dev/` — игра;
- `https://<твой-проект>.pages.dev/admin.html` — просмотр ответов.

**Важно:** без `QUIZ_RESULTS` отправка ответов недоступна, без `ADMIN_PASSWORD` админка недоступна. Пароль администратора **не добавлять в GitHub-файлы**.

## Изменить вопросы
Отредактируй `functions/_lib/quiz.js`: для каждого вопроса `title`, `options`, `correct` — индекс правильного ответа с 0.

Сейчас там только демонстрационные вопросы. Репозиторий **публичный**: любой, кто найдёт его, сможет посмотреть правильные ответы в исходном коде. Для личной викторины с секретными ответами перед игрой переведи репозиторий в Private либо перенеси ключ ответов в Cloudflare Secret.

## Примечания
- Панель показывает последние 100 записанных попыток, в обратном хронологическом порядке.
- Ключи хранятся в Cloudflare KV; возможна небольшая задержка отображения между регионами.
- Для теста можно отправить несколько попыток. Уникального запрета на повторную игру в этой первой версии нет.
- Если страница открывается без Cloudflare Pages Functions (например, напрямую из GitHub), API и сохранение результатов не будут работать.
